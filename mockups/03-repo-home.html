dot — XL/Axis CLI Package Tool

Tools untuk pembelian paket data XL Axis lewat command line dengan TUI interface.

Installation

python main.py

Features

  • Login menggunakan nomor & password
  • Browse semua paket aktif (XUT, Family, dll)
  • Pembelian via DANA / GoPay / Pulsa
  • Cek sisa kuota terkini
